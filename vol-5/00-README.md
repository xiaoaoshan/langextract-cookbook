# 从一条快递短信开始：LangExtract 源码阅读教材

本书的目标，是和读者一起写出一个能从生活文本中找出信息、整理信息，并在原文中标记证据的程序。你不需要先认识任何 LangExtract 的类。

## 阅读方法

建议先打开每章的教学实验，在 Python 解释器中运行。实验使用标准库和虚构数据，不需要模型账号。随后阅读对应的正式源码；不要把教学简化实现当成项目本身。

源码版本：[google/langextract @ b3499195e5ee711d3bb7da5178ba40456046f5f3](https://github.com/google/langextract/tree/b3499195e5ee711d3bb7da5178ba40456046f5f3)。源码版权归原作者，Apache-2.0。正文中摘录保留原代码拼写和逻辑。
