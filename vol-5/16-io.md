# 第 16 章　保存和重新打开登记卡

我们已经把一个月的快递短信整理好了。关掉程序，登记卡却全部消失，因为它们一直待在内存里。现在要让明天的程序、其他 Python 程序，甚至没有安装 LangExtract 的人也能读取结果。

## 16.1 Python 对象不是文件格式

```python
from dataclasses import dataclass, asdict
from enum import Enum
import json

class Match(Enum):
    EXACT = "exact"

@dataclass
class Card:
    text: str
    status: Match

card = Card("0038", Match.EXACT)
print(asdict(card))
record = {"text": card.text, "status": card.status.value}
encoded = json.dumps(record, ensure_ascii=False)
loaded = json.loads(encoded)
assert Card(loaded["text"], Match(loaded["status"])) == card
```

asdict 会把 dataclass 展开成字典，但枚举不一定能被普通 JSON 编码器直接处理。保存时要转为枚举值，读取后则还原枚举类型。保存的是表示形式，不是对象的内存地址。

取件码 "0038" 仍为字符串。不能为了省事把所有看起来像数字的文本转成整数。

## 16.2 为 dataclass 定制转换规则

源码出处：[langextract/data_lib.py:28–55](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/data_lib.py#L28-L55)。

````python
def enum_asdict_factory(items: Iterable[tuple[str, Any]]) -> dict[str, Any]:
  """Custom dict_factory for dataclasses.asdict.

  Recursively converts dataclass instances, converts enum values to their
  underlying values, converts integral numeric types to int, and skips any
  field whose name starts with an underscore.

  Args:
    items: An iterable of (key, value) pairs from fields of a dataclass.

  Returns:
    A mapping of field names to their values, with special handling for
    dataclasses, enums, and numeric types.
  """
  result: dict[str, Any] = {}
  for key, value in items:
    # Skip internal fields.
    if key.startswith("_"):
      continue
    if dataclasses.is_dataclass(value):
      result[key] = dataclasses.asdict(value, dict_factory=enum_asdict_factory)
    elif isinstance(value, enum.Enum):
      result[key] = value.value
    elif isinstance(value, numbers.Integral) and not isinstance(value, bool):
      result[key] = int(value)
    else:
      result[key] = value
  return result
````

enum_asdict_factory 接收一组 (字段名, 值) 对。下划线开头的内部字段不参与保存；遇 dataclass 继续使用同一工厂递归转字典，枚举取 .value，整数类数值（不含 bool）转为原生 int，其余照常保留。

这样保存的数据无需携带纯内部缓存，类似 NumPy 整数之类的实现细节也不会妨碍 JSON 编码。注意这是 dataclasses.asdict 的字典构造钩子，并不是能转换任意容器中所有自定义对象的通用序列化器。属性值仍应符合项目所需的数据类型。

源码出处：[langextract/data_lib.py:58–83](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/data_lib.py#L58-L83)。

````python
def annotated_document_to_dict(
    adoc: data.AnnotatedDocument | None,
) -> dict[str, Any]:
  """Converts an AnnotatedDocument into a Python dict.

  This function converts an AnnotatedDocument object into a Python dict, making
  it easier to serialize or deserialize the document. Enum values and NumPy
  integers are converted to their underlying values, while other data types are
  left unchanged. Private fields with an underscore prefix are not included in
  the output.

  Args:
    adoc: The AnnotatedDocument object to convert.

  Returns:
    A Python dict representing the AnnotatedDocument.
  """

  if not adoc:
    return {}

  result = dataclasses.asdict(adoc, dict_factory=enum_asdict_factory)

  result["document_id"] = adoc.document_id

  return result
````

annotated_document_to_dict 接收 AnnotatedDocument 或 None；空对象输入返回空字典，否则调用 dataclasses.asdict 并传入上述工厂，最后明确写入 adoc.document_id。这个属性可能按需产生文档 ID，因此不能仅从内部字段复制。

这里保存的字段名称是内部登记卡的表示，不是第 3 章模型答卷里按抽取类别命名的键。两种 JSON 服务于不同边界：答卷是模型接口，持久化文件是应用的数据接口。

## 16.3 反方向的转换不能直接调用构造器

源码出处：[langextract/data_lib.py:86–133](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/data_lib.py#L86-L133)。

````python
def dict_to_annotated_document(
    adoc_dic: Mapping[str, Any],
) -> data.AnnotatedDocument:
  """Converts a Python dict back to an AnnotatedDocument.

  Args:
    adoc_dic: A Python dict representing an AnnotatedDocument.

  Returns:
    A new AnnotatedDocument that shares no mutable state with `adoc_dic`.
    Extractions saved as null are restored as None.
  """
  if not adoc_dic:
    return data.AnnotatedDocument()

  # AnnotatedDocument.extractions defaults to None, which is saved as null.
  raw_extractions = adoc_dic.get("extractions", [])
  extractions = []
  for ext_dic in raw_extractions or []:
    # Work on copies so the caller's dict is not mutated and does not share
    # attributes with the returned extraction.
    ext_dic = dict(ext_dic)
    ext_dic["attributes"] = copy.deepcopy(ext_dic.get("attributes"))
    token_int = ext_dic.get("token_interval")
    if token_int:
      ext_dic["token_interval"] = tokenizer.TokenInterval(**token_int)
    else:
      ext_dic["token_interval"] = None

    char_int = ext_dic.get("char_interval")
    if char_int:
      ext_dic["char_interval"] = data.CharInterval(**char_int)
    else:
      ext_dic["char_interval"] = None

    status_str = ext_dic.get("alignment_status")
    if status_str:
      ext_dic["alignment_status"] = data.AlignmentStatus(status_str)
    else:
      ext_dic["alignment_status"] = None

    extractions.append(data.Extraction(**ext_dic))

  return data.AnnotatedDocument(
      document_id=adoc_dic.get("document_id"),
      text=adoc_dic.get("text"),
      extractions=None if raw_extractions is None else extractions,
  )
````

dict_to_annotated_document 从空字典建立默认 AnnotatedDocument；若有 extractions，则逐项浅复制卡片字典，然后深复制 attributes，避免新对象与调用方共享可变属性。token_interval 字典构造成 TokenInterval，char_interval 构造成 data.CharInterval，非空状态字符串转回 AlignmentStatus。缺失或空字段置 None。

最后用 document_id、text、extractions 创建新文档。尤其注意三种情况：缺少 extractions 键使用 []；explicit null 保留 None；空列表仍为空列表。这些情况不能简单用 or [] 一律替代。

为什么不直接 AnnotatedDocument(**adoc_dic)？它不会自动把内部字典变成 Extraction、区间或枚举对象；后续访问 e.char_interval.start_pos 就会遇到类型错误。

## 16.4 为什么不直接把所有文档装在一个 JSON 数组？

一个月的短信还不算多，如果是十年的记录呢？JSON Lines（JSONL）约定一行一个完整 JSON 值。读一行就可恢复一份登记卡，不必等待整个文件解析完毕。

```python
import json
import io

records = [{"document_id": "a", "text": "取件码 0038"},
           {"document_id": "b", "text": "取件码 9246"}]
stream = io.StringIO()
for record in records:
    stream.write(json.dumps(record, ensure_ascii=False) + "\n")
stream.seek(0)
assert [json.loads(line) for line in stream] == records
```

这里用 StringIO 模拟文件，不接触硬盘。json.dumps 会把字符串内部的换行转义，所以即便原短信含换行，记录仍占一行。

源码出处：[langextract/io.py:38–39](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L38-L39)。

源码出处：[langextract/io.py:87–143](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L87-L143)。

````python
def save_annotated_documents(
    annotated_documents: Iterator[data.AnnotatedDocument],
    output_dir: pathlib.Path | str | None = None,
    output_name: str = 'data.jsonl',
    show_progress: bool = True,
) -> None:
  """Saves annotated documents to a JSON Lines file.

  Args:
    annotated_documents: Iterator over AnnotatedDocument objects to save.
    output_dir: The directory to which the JSONL file should be written.
      Can be a Path object or a string. Defaults to 'test_output/' if None.
    output_name: File name for the JSONL file. Not sanitized; callers
      passing untrusted input (e.g. in a hosted service) should validate
      it first (reject `..`, absolute paths, etc.) to avoid writing
      outside `output_dir`.
    show_progress: Whether to show a progress bar during saving.

  Raises:
    IOError: If the output directory cannot be created.
    InvalidDatasetError: If no documents are produced.
  """
  if output_dir is None:
    output_dir = pathlib.Path('test_output')
  else:
    output_dir = pathlib.Path(output_dir)

  output_dir.mkdir(parents=True, exist_ok=True)

  output_file = output_dir / output_name
  has_data = False
  doc_count = 0

  # Create progress bar
  progress_bar = progress.create_save_progress_bar(
      output_path=str(output_file), disable=not show_progress
  )

  try:
    with open(output_file, 'w', encoding='utf-8') as f:
      for adoc in annotated_documents:
        if not adoc.document_id:
          continue

        doc_dict = data_lib.annotated_document_to_dict(adoc)
        f.write(json.dumps(doc_dict, ensure_ascii=False) + '\n')
        has_data = True
        doc_count += 1
        progress_bar.update(1)
  finally:
    progress_bar.close()

  if not has_data:
    raise InvalidDatasetError(f'No documents to save in: {output_file}')

  if show_progress:
    progress.print_save_complete(doc_count, str(output_file))
````

save_annotated_documents 选择输出目录（未指定时 test_output），创建目录，组合 output_name。建立按文档数更新的进度条；用 UTF-8 和写入模式打开文件，读取迭代器中的每个 AnnotatedDocument，缺 ID 跳过，转换为字典后 dumps 并追加换行，记录数量。finally 保证关闭进度显示。未写任何文档时抛 InvalidDatasetError；成功且 show_progress 时打印摘要。

它不是事务：采用 w 会覆盖现有目标，异常前可能已经留下部分记录。应用应选择受信任的输出目录与文件名，并对重要输出另作备份；必要时使用独立临时文件，在全部写入成功后再替换。

源码出处：[langextract/io.py:146–192](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L146-L192)。

````python
def load_annotated_documents_jsonl(
    jsonl_path: pathlib.Path,
    show_progress: bool = True,
) -> Iterator[data.AnnotatedDocument]:
  """Loads annotated documents from a JSON Lines file.

  Args:
    jsonl_path: The file path to the JSON Lines file.
    show_progress: Whether to show a progress bar during loading.

  Yields:
    AnnotatedDocument objects.

  Raises:
    IOError: If the file does not exist or is invalid.
  """
  if not os.path.exists(jsonl_path):
    raise IOError(f'File does not exist: {jsonl_path}')

  # Get file size for progress bar
  file_size = os.path.getsize(jsonl_path)

  # Create progress bar
  progress_bar = progress.create_load_progress_bar(
      file_path=str(jsonl_path),
      total_size=file_size if show_progress else None,
      disable=not show_progress,
  )

  doc_count = 0

  try:
    with open(jsonl_path, 'r', encoding='utf-8') as f:
      for line in f:
        progress_bar.update(len(line.encode('utf-8')))

        line = line.strip()
        if not line:
          continue
        doc_dict = json.loads(line)
        doc_count += 1
        yield data_lib.dict_to_annotated_document(doc_dict)
  finally:
    progress_bar.close()

  if show_progress:
    progress.print_load_complete(doc_count, str(jsonl_path))
````

先检查路径存在，取得文件字节数建立进度条，再逐行读取。每行按 UTF-8 编码长度更新显示，strip 后空行跳过，json.loads 后交给 dict_to_annotated_document 还原，并 yield 一份文档。finally 关闭显示，正常迭代完成后打印摘要。

这是生成器，调用它仅建立迭代对象，实际读文件发生在迭代时。一份损坏记录会令当前读取失败；它不自动跳过坏 JSON，也不一次性把整份文件装入列表。调用者若提前停止消费，应及时关闭生成器。

## 16.5 输入文件原来可能是一张表

接下来想读取 CSV 文档列表。假设表格有编号、内容两列，但取件码或 ID 可能以零开头。表格里还有 "NA" 这种正常文本，不应默认为缺失值。

```python
import csv
import io

rows = csv.DictReader(io.StringIO('id,text\n0038,"短信,已到"\n,NA\n'))
a, b = list(rows)
assert a["id"] == "0038"
assert a["text"] == "短信,已到"
assert b == {"id": "", "text": "NA"}
```

手写 line.split(",") 无法正确处理引号中的逗号。实际项目使用 pandas 来解析 CSV。

源码出处：[langextract/io.py:195–231](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L195-L231)。

````python
def _read_csv(
    filepath: pathlib.Path, column_names: list[str], delimiter: str = ','
) -> Iterator[dict[str, Any]]:
  """Reads a CSV file and yields rows as dicts.

  Args:
    filepath: The path to the file.
    column_names: The names of the columns to read.
    delimiter: The delimiter to use when reading the CSV file.

  Yields:
    An iterator of dicts representing each row.

  Raises:
    IOError: If the file does not exist.
    InvalidDatasetError: If the dataset is empty or invalid.
  """
  if not os.path.exists(filepath):
    raise IOError(f'File does not exist: {filepath}')

  try:
    with open(filepath, 'r', encoding='utf-8') as f:
      df = pd.read_csv(
          f,
          usecols=column_names,
          dtype=str,
          delimiter=delimiter,
          # Otherwise, pandas reads 'NA', 'NULL' and empty fields as NaN, even
          # with dtype=str.
          keep_default_na=False,
      )
      for _, row in df.iterrows():
        yield row.to_dict()
  except pd.errors.EmptyDataError as e:
    raise InvalidDatasetError(f'Empty dataset: {filepath}') from e
  except ValueError as e:
    raise InvalidDatasetError(f'Invalid dataset file: {filepath}') from e
````

_read_csv 检查路径，用 UTF-8 打开，pd.read_csv 只读取指定列、指定分隔符，dtype=str 保留文本类型，keep_default_na=False 保留 NA、NULL 和空值为文字。通过 iterrows 将每行转为 dict。EmptyDataError 和 ValueError 分别包装为 InvalidDatasetError，保留原异常链。

这里返回迭代器，但 pandas 仍先物化 DataFrame；与真正逐行读取 JSONL 不同，不能把它误称为低内存 CSV 流式解析。

源码出处：[langextract/io.py:42–84](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L42-L84)。

````python
@dataclasses.dataclass(frozen=True)
class Dataset(abc.ABC):
  """A dataset for inputs to LLM Labeler."""

  input_path: pathlib.Path
  id_key: str
  text_key: str

  def load(self, delimiter: str = ',') -> Iterator[data.Document]:
    """Loads the dataset from a CSV file.

    Args:
      delimiter: The delimiter to use when reading the CSV file.

    Yields:
      A Document for each row in the dataset. Rows with an empty ID get a
      generated document ID.

    Raises:
      IOError: If the file does not exist.
      InvalidDatasetError: If the dataset is empty or invalid.
      NotImplementedError: If the file type is not supported.
    """
    if not os.path.exists(self.input_path):
      raise IOError(f'File does not exist: {self.input_path}')

    if str(self.input_path).endswith('.csv'):
      try:
        csv_data = _read_csv(
            self.input_path,
            column_names=[self.text_key, self.id_key],
            delimiter=delimiter,
        )
      except InvalidDatasetError as e:
        raise InvalidDatasetError(f'Empty dataset: {self.input_path}') from e
      for row in csv_data:
        yield data.Document(
            text=row[self.text_key],
            # An empty ID would be skipped on save and collide across rows.
            document_id=row[self.id_key] or None,
        )
    else:
      raise NotImplementedError(f'Unsupported file type: {self.input_path}')
````

Dataset 是冻结的 dataclass（继承 abc.ABC，但没有抽象方法），保存输入路径、ID 列名和原文列名。load 首先确认文件存在，只支持 .csv，调用 _read_csv 并逐行产生 Document。空 ID 传 None，使 Document 后续可生成 ID。将无效数据错误包装成包含路径的异常；其他扩展名报 NotImplementedError。

这种设计让输入表与抽取流水线隔离：第 11 章只消费 Document，不认识 pandas。

## 16.6 从地址读取原文

默认 extract 把字符串当作文本，用户明确选择 fetch_urls 才把 URL 当作下载目标。下载和文字抽取应保持为独立步骤。

源码出处：[langextract/io.py:234–270](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L234-L270)。

````python
def is_url(text: str) -> bool:
  """Check if the given text is a valid URL.

  Uses urllib.parse to validate that the text is a properly formed URL
  with http or https scheme and a valid network location.

  Args:
    text: The string to check.

  Returns:
    True if the text is a valid URL with http(s) scheme, False otherwise.
  """
  if not text or not isinstance(text, str):
    return False

  text = text.strip()

  # Reject text with whitespace (not a pure URL)
  if ' ' in text or '\n' in text or '\t' in text:
    return False

  try:
    result = urlparse.urlparse(text)
    hostname = result.hostname

    # Must have valid scheme, netloc, and hostname
    if not (result.scheme in ('http', 'https') and result.netloc and hostname):
      return False

    # Accept IPs, localhost, or domains with dots
    try:
      ipaddress.ip_address(hostname)
      return True
    except ValueError:
      return hostname == 'localhost' or '.' in hostname
  except (ValueError, AttributeError):
    return False
````

is_url 拒绝空值、非字符串及含指定空白的内容；strip 后用标准库解析地址，确认 HTTP(S) scheme、网络位置和主机存在，再判断主机是否符合其语法启发规则。它只是判断输入像不像 URL，绝不能当作网络访问授权或防护机制。不可信输入不应直接触发服务端下载。

源码出处：[langextract/io.py:273–361](https://github.com/google/langextract/blob/b3499195e5ee711d3bb7da5178ba40456046f5f3/langextract/io.py#L273-L361)。

````python
def download_text_from_url(
    url: str,
    timeout: int = DEFAULT_TIMEOUT_SECONDS,
    show_progress: bool = True,
    chunk_size: int = 8192,
) -> str:
  """Download text content from a URL with optional progress bar.

  Args:
    url: The URL to download from.
    timeout: Request timeout in seconds.
    show_progress: Whether to show a progress bar during download.
    chunk_size: Size of chunks to download at a time.

  Returns:
    The text content of the URL.

  Raises:
    requests.RequestException: If the download fails.
    ValueError: If the content is not text-based.
  """
  try:
    # Make initial request to get headers. Use a `with` block so the
    # streamed Response is closed even if iter_content raises mid-stream.
    with requests.get(url, stream=True, timeout=timeout) as response:
      response.raise_for_status()

      # Check content type
      content_type = response.headers.get('Content-Type', '').lower()
      if not any(
          ct in content_type
          for ct in ['text/', 'application/json', 'application/xml']
      ):
        # Try to proceed anyway, but warn
        print(f"Warning: Content-Type '{content_type}' may not be text-based")

      # Get content length for progress bar
      total_size = int(response.headers.get('Content-Length', 0))

      filename = url.split('/')[-1][:50]

      # Download content with progress bar
      chunks = []
      if show_progress and total_size > 0:
        progress_bar = progress.create_download_progress_bar(
            total_size=total_size, url=url
        )

        try:
          for chunk in response.iter_content(chunk_size=chunk_size):
            if chunk:
              chunks.append(chunk)
              progress_bar.update(len(chunk))
        finally:
          progress_bar.close()
      else:
        # Download without progress bar
        for chunk in response.iter_content(chunk_size=chunk_size):
          if chunk:
            chunks.append(chunk)

      # Combine chunks and decode
      content = b''.join(chunks)

      # Try to decode as text
      encodings = ['utf-8', 'latin-1', 'ascii', 'utf-16']
      text_content = None
      for encoding in encodings:
        try:
          text_content = content.decode(encoding)
          break
        except UnicodeDecodeError:
          continue

      if text_content is None:
        raise ValueError(f'Could not decode content from {url} as text')

      # Show content summary with clean formatting
      if show_progress:
        char_count = len(text_content)
        word_count = len(text_content.split())
        progress.print_download_complete(char_count, word_count, filename)

      return text_content

  except requests.RequestException as e:
    raise requests.RequestException(
        f'Failed to download from {url}: {str(e)}'
    ) from e
````

download_text_from_url 使用 requests 的流式响应和上下文管理器，先检查 HTTP 状态，检查内容类型并对可能非文本的回复发警告。已知总字节数时显示下载进度，逐块收集非空字节，最终 join 后尝试解码。

源码的编码顺序是 UTF-8、Latin-1、ASCII、UTF-16；Latin-1 可以解码任意字节序列，所以后两个通常不会被尝试。虽然网络读取按块进行，最后仍保留完整 bytes 和解码文本，不等于有文档大小上限。外部内容与响应头不可信时应由调用层实施地址授权、网络隔离、内容和字节预算等防护。这里只讲读取与解码职责，不把 URL 语法检查当作安全策略。

读取失败时包装 requests.RequestException，保留原异常；响应及进度条在相应上下文/finally 中关闭。

````python
def create_download_progress_bar(
    total_size: int, url: str, ncols: int = 100, max_url_length: int = 50
) -> tqdm.tqdm:
  """Create a styled progress bar for downloads.

  Args:
    total_size: Total size in bytes.
    url: The URL being downloaded.
    ncols: Number of columns for the progress bar.
    max_url_length: Maximum length to show for the URL.

  Returns:
    A configured tqdm progress bar.
  """
  # Truncate URL if too long, keeping the domain and end
  if len(url) > max_url_length:
    parsed = urllib.parse.urlparse(url)
    domain = parsed.netloc or parsed.hostname or "unknown"

    path_parts = parsed.path.strip("/").split("/")
    filename = path_parts[-1] if path_parts and path_parts[-1] else "file"

    available = max_url_length - len(domain) - len(filename) - 5
    if available > 0:
      url_display = f"{domain}/.../{filename}"
    else:
      url_display = url[: max_url_length - 3] + "..."
  else:
    url_display = url

  return tqdm.tqdm(
      total=total_size,
      unit="B",
      unit_scale=True,
      desc=(
          f"{BLUE}{BOLD}LangExtract{RESET}: Downloading"
          f" {GREEN}{url_display}{RESET}"
      ),
      bar_format=(
          "{desc}: {percentage:3.0f}%|{bar}| {n_fmt}/{total_fmt}"
          " [{elapsed}<{remaining}, {rate_fmt}]"
      ),
      colour=GOOGLE_BLUE,
      ncols=ncols,
  )
````

create_download_progress_bar 根据 URL 长度决定显示完整地址或缩短描述，尽量保留域名及文件末名。建立总字节数已知的 tqdm，单位 B、自动单位缩放、百分比及耗时/剩余时间。显示只是辅助，不能作为下载目标的安全验证。
